规则 / Rules

  • 主题必须以四个前缀之一开头（见按钮小字）。Subject must start with one of the four prefixes.
  • 一封邮件只办一件事。One email = one request.
  • 投稿/更新请附加 .dll（可选 preview.png）；附件过大（约 >40MB）请写网盘链接。
  • 不要主动发送源码。Do not send source unless asked.
